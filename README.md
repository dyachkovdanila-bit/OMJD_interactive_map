# Атлас МОЖД

Интерактивная карта построек Московской окружной железной дороги (1903–1908, арх. А. Н. Померанцев): сохранившиеся объекты с охранным статусом и без него, утраченные и перенесённые постройки, мосты и путепроводы. Точку можно открыть: в карточке — листы альбомов чертежей 1908–1909 гг., современные и исторические фото, дата и обстоятельства утраты.

Открыть: `index.html` в браузере (работает и с диска) или страница GitHub Pages.

Подложки: по умолчанию — тайлы OpenStreetMap France (серые или цветные, русские подписи) и Esri; они работают и при открытии файла с диска. Стандартные тайлы openstreetmap.org отдаются только сайтам (нужен заголовок Referer), поэтому этот вариант доступен только на GitHub Pages. CARTO с сентября 2026 г. требует ключ — бесплатный некоммерческий ключ можно получить на carto.com/basemaps/apikey и вписать в `config.js`.

## Что внутри

| Путь | Содержимое |
|---|---|
| `index.html`, `assets/` | страница, стили, логика карты (Leaflet 1.9.4 лежит в `assets/vendor/`) |
| `data/objects.js` | каталог: 164 объекта и 17 станций, ссылки на листы альбомов, метаданные фото Commons |
| `data/overlays.js` | список исторических слоёв и их привязка |
| `data/ring.js` | линия кольца (OpenStreetMap) |
| `overlays/plan1908`, `plan1917`, `plan1941` | привязанные общие планы Москвы (фрагменты WebP с прозрачностью) |
| `overlays/st_*` | привязанные планы станций из альбома 1909 г., т. I (Лихоборы, Черкизово, Андроновка, Лефортово, Серебряный Бор) |
| `img/gpib/` | фото из «Альбома сооружений Московской окружной ж. д.» 1908 г. (ГПИБ), `*_s.webp` — превью |

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту-две сайт откроется по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

Pages для **приватного** репозитория доступен только на платных тарифах GitHub (Pro и выше). На бесплатном тарифе репозиторий нужно сделать публичным.

## Источники и лицензии

- Альбом исполнительных типовых чертежей МОЖД 1903–1908 гг., т. I–II — Wikimedia Commons, общественное достояние. Листы в карточках показываются напрямую с Commons.
- «Альбом [сооружений] Московской окружной жел. дор.», М., 1908 — электронная библиотека ГПИБ, общественное достояние.
- Фото Главархива Москвы — CC BY 4.0. Остальные фото — авторы и лицензии указаны под каждым снимком (Wikimedia Commons).
- Перечень объектов культурного наследия — по спискам Викигида (ru.wikivoyage.org).
- Даты утрат — хроники «Архнадзора», um.mos.ru, публикации краеведов (указаны в карточках).
- Подложки и линия кольца — © участники OpenStreetMap, © CARTO, © Esri.
- План Москвы изд. Суворина (1917) и немецкий военно-географический план (1941) — Wikimedia Commons.

Точность привязки: общие планы — от 30–60 м (1908) до 100–200 м (1941); планы станций — около 5–15 м. Положение части утраченных построек приблизительное, такие точки обведены пунктиром.
